# Atualização antes de editar

- Antes de alterar o projeto, confira `git status` e atualize a referência remota com `git fetch origin`.
- Com a árvore limpa, execute `git pull --ff-only` e confirme que a branch incorpora os commits remotos antes de editar.
- Se houver alterações locais, preserve-as antes de integrar atualizações. Nunca descarte trabalho sem autorização do usuário.
- Se a atualização falhar ou houver divergência, informe o problema; não trate a referência local `origin/main` como confirmação de que os arquivos estão atuais.
