# Ilustrações vetorizadas do Everkinetic

O Everkinetic (<https://github.com/everkinetic/data>, CC BY-SA 4.0) não publica SVG para alguns
exercícios, só PNG (`src/images-web/<nome>-1.png` e `-2.png`). Estes arquivos são esses PNGs
vetorizados, no mesmo formato do `dist/svg` do Everkinetic, para o `import-illustrations.ts` tratá-los
como os outros. Seguem sob CC BY-SA 4.0.

| Id | Everkinetic | No app |
|---|---|---|
| 0003 | seated-shoulder-press-machine | Desenvolvimento Máquina |
| 0012 | dumbbell-shoulder-press | Desenvolvimento com Halteres |
| 0047 | butterfly-machine | Peck Deck (Voador) |

Como foram gerados (20/10/2026): potrace 2.1.8 (npm), `threshold: 160`, `turdSize: 4`,
`optTolerance: 0.4`; coordenadas arredondadas para inteiros; `-1.png` vira `relaxation` e `-2.png`
vira `tension`.
