J. Decisão Tecnológica: Composer vs Kotlin
Resposta curta: continue com Capacitor. Kotlin puro não compensa para este projeto.

Comparação
Critério	Capacitor	Kotlin Nativo
Performance	WebView; diferença perceptível só em jogos, animações complexas, ML embarcado 	Máxima
Custo	1 codebase; você já tem o web pronto	2 codebases (iOS + Android) ou só Android
Manutenção	Web ecosystem; plugins variam de qualidade 	Ferramentas maduras
Curva de aprendizado	Você já domina	Nova stack para manter
Distribuição	1 build → ambos os stores	Build separado por plataforma
Deep hardware	Via plugins (BLE, NFC, câmera avançada) 	Acesso direto
Notificações agendadas	Requer plugin (@capacitor/local-notifications) 	Sim
